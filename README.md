This project focuses on analyzing and forecasting sales data using Microsoft Excel and Power BI. The dataset includes key business attributes such as order date, sales, profit, region, category, and shipping mode. Excel was used for data cleaning and preprocessing, while Power BI was utilized for data modeling, DAX calculations, and building an interactive dashboard. The dashboard provides insights into sales performance across regions, segments, and categories, along with monthly trends and geographical analysis. It also incorporates time-series forecasting to predict future sales patterns. Key findings reveal higher sales towards the year-end, strong performance from the consumer segment and office supplies category, and significant contribution from standard shipping. Overall, the project delivers a dynamic and user-friendly solution that helps in understanding business performance and supports data-driven decision-making.
